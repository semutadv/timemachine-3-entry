One warning label, at most 120 characters, for a time machine. This entry
speaks to the trip every traveller is secretly planning — back to 2020 to
"fix things" — and voids the only two things they were counting on: the
warranty, and causality.

`main.ts` (Node 22, no dependencies) writes the label to `entry.txt` in the
output directory, clearing the directory's contents first and adding no
trailing newline.
